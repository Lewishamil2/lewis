# 一键拆表

Windows 桌面版 Excel 拆表工具。选择工作簿、工作表和拆分依据列后，按该列的取值生成多个工作表或多个独立文件。

## 最新版本：V4.8

下载 [一键拆表-V4.8.exe](./一键拆表-V4.8.exe)，按 [V4.8 使用方法](./一键拆表-V4.8-使用方法.txt) 操作。V4.8 修复了同名结果覆盖、保留工作表时命名区域丢失、相对路径超链接误报、选择旧格式后沿用旧文件，以及拆分表图片/图表丢失等问题。源文件见 [V4.8 源码](./一键拆表-V4.8-源码.py)。

支持 `.xlsx`、`.xlsm` 和 `.xlsb`；处理 `.xlsb` 需要本机安装可通过 COM 调用的 WPS 表格或 Microsoft Excel。`.xlsm` / `.xlsb` 拆分后的 `.xlsx` 不保留宏。
