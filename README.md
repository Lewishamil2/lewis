# 一键拆表 V3

Windows 桌面版 Excel 拆表工具。选择工作簿、工作表和拆分依据列后，可按该列的取值生成多个工作表或多个独立文件。

## 下载与使用

1. 下载仓库中的 [一键拆表-V3.exe](./一键拆表-V3.exe)。
2. 在 Windows 上运行程序，选择 Excel 文件、工作表和拆分依据列。
3. 按需要设置数据起始行，选择是否将空白值单独拆分。
4. 选择输出方式，执行拆分。

## 输出方式

- **拆到当前工作簿**：在原文件内按取值生成多个工作表，保留原工作表。
- **拆成多个文件**：每个取值生成一个独立的 `.xlsx` 文件，保存到指定文件夹。

数据起始行之前的行会作为表头保留在每个结果顶部。具体说明见 [使用方法](./一键拆表-V3-使用方法.txt)。
