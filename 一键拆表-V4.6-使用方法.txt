一键拆表工具 V4.6（tkinter 版，替代 WPS 智能工具箱会员功能）
海上钢琴师出品（不是上海钢琴师，不是上海~不是上海）

用法：选择 Excel 文件 -> 选工作表 -> 选拆分依据列 -> 可选数据起始行 -> 一键拆分
支持格式：.xlsx / .xlsm / .xlsb
支持两种模式：
  1. 拆到新工作簿：源文件不动，另存为「原名-拆分.xlsx」，原有工作表一并保留
  2. 拆成多个文件：每个取值生成一个独立 xlsx 到指定文件夹
     （默认把源文件的其他工作表也一并带进每个文件）


====================  V4.6 修好了什么（相对 V4.5）  ====================

【重要 · 筛选按钮跑到数据行上了】

  现象：前三行是表头、从第 4 行开始拆，拆出来的文件里**筛选按钮出现在第 4 行**
  （第一行数据上），本该在第 3 行（表头的最后一行）。
  根因：程序重建自动筛选范围时，拿「数据起始行」当成了筛选按钮所在行：
        <autoFilter ref="A4:OV162397"/>   ← 按钮被放在第 4 行
  自动筛选的 ref 起始行就是**按钮所在的那一行**，所以按钮跟着数据跑下去了。
  顺带还有个小毛病：重建标签时把源表自带的**筛选条件**（比如某一列筛了
  "专案二室"）和 WPS 的扩展属性一起丢掉了。

  修法：
  - 按钮行改为「表头最后一行」（数据起始行 - 1）；
  - 源表筛选范围的起始行如果在表头区，就直接沿用源表的行号
    （表头是原样复制的，行号不变），多行表头也不会错位；
  - 只替换 ref 属性，筛选条件和 WPS 扩展属性原样保留。
  实测：三行表头 + 数据从第 4 行 → 拆出来是 <autoFilter ref="A3:OV162374">，
  筛选条件和"专案二室"都还在。

【重要 · 拆出来的文件里看不到源文件的其它工作表】

  现象：源工作簿里有「实时终端台账」和「Sheet1」两张表，只拆台账，
  拆出来的文件里 Sheet1 不见了。
  原因：「拆成多个文件」是流式组装，只写了一张工作表，包里的登记表
  （workbook.xml / 关系表 / 内容类型）也只登记了一张。
  修法：新增选项「保留源文件的其他工作表」，**默认勾选**。
  开启后每个输出文件里 = 拆出的数据表（排第一）+ 源文件里其它工作表
  （按原顺序跟在后面，部件原样搬运）。
  取消勾选则回到旧行为（每个文件只有拆出的那一张表）。

  实现上有个坑顺手填了：共享字符串表为了缩小体积做过「子集化」
  （把本组没用到的文字条目置空）。保留其它工作表时，必须把这些表引用到的
  文字条目也一并保留，否则那些表打开是**一片空白而数字还在**，极难排查。
  实测：输出的共享字符串条目数与源表一致（1,121,425 条），Sheet1 的文字完好。

  注：「拆到新工作簿」模式本来就保留全部工作表，不受这个选项影响。


====================  V4.5 修好了什么（相对 V4.4，仍然有效）  ====================

【重要 · 支持 xlsb（二进制工作簿）】
  选 .xlsb 不再报「无法打开文件」。程序会先调用本机 WPS 表格 / Microsoft Excel
  把它另存为 xlsx 再拆（Office 自己转的，格式公式完全保真）。
  - 需要本机装有 WPS 或 Excel；
  - 180MB 的文件首次转换约 70~150 秒，期间别关 WPS 窗口；
  - 转换结果缓存在 %LOCALAPPDATA%\一键拆表\xlsb缓存\，第二次打开直接用缓存，
    源文件一改缓存自动失效；这个目录可以随时手动清空。

【重要 · 只拆选定的表，其他子表不再被动】
  「拆到当前工作簿」改为「拆到新工作簿」：源文件一个字节都不改，
  结果另存为源文件所在目录的「<原名>-拆分.xlsx」，原有工作表全部带过去。
  不会再生成 .backup.xlsx 备份（因为根本不需要了）。

【致命 · 大表拆到一半失败（V4.4 就有的老毛病）】
  工作表 XML 超过 zipfile 的 2GB 硬限制会抛
  RuntimeError: File size too large。已改为始终按 zip64 写。
  16 万行 × 412 列的台账实测通过（单个输出 324MB）。


====================  V4.4 / V4.3 修好了什么（仍然有效）  ====================

【V4.4】共享公式 / 普通公式拆出来引用错行 —— 统一按「旧行号 -> 新行号」平移；
        取值恰好是"(空白)"时不再静默丢数据。
【V4.3】拆出来的表格在 WPS / Excel 里一片空白 —— 关系表里的路径写多了一层
        xl/，导致找不到样式表和字符串表；已修，并新增出包结构自检。


====================  使用建议  ====================

  - 大表第一次选工作表 / 选列时，后台统计需要十几秒，属正常现象，
    界面不会卡住，状态栏会显示进度和已用时间。同一文件再操作会明显更快（走缓存）。
  - 「数据起始行」填**第一行数据**的行号。前三行是表头就填 4；
    程序会把第 1 行 ~ 起始行-1 原样保留，并把筛选按钮放在第「起始行-1」行。
  - 「拆到新工作簿」会把整个工作簿读进内存，超大的表（几千万单元格）会被
    内存体检拦下并提示改用「拆成多个文件」—— 那条通道是流式的，多大都不怕。
  - 源文件是 .xlsm / .xlsb（可能含宏）时：两种拆分模式都不保留宏，程序会提示。
  - 拆分依据列最好是没有空白的列；有空白的行默认不拆出，可勾选「空白行也拆出」。
  - 拆分过程会在输出文件夹所在盘产生一个临时文件（`一键拆表-*.spool`），
    正常结束会自动删除；如果程序被强制关闭，可以手动删掉它。
  - 如果拆到一半失败，先去源文件所在文件夹看「一键拆表-错误日志.txt」，
    里面记录了完整的出错位置。
  - 带公式的表格拆分后，公式会跟着行号平移，引用仍指向"同一行"的数据；
    数组公式（{=...}）保持原样不平移（其缓存值会一并带过去）。


====================  自检  ====================

  如果怀疑程序有问题，可以运行自检：
      一键拆表-V4.6.exe --selftest 报告.txt
  程序会把环境与核心功能的检查结果写进 报告.txt（最后一行 RESULT=PASS 表示正常）。
  自检会报告 comtypes 版本与本机 Office COM 注册情况（xlsb 转换的前提）。
