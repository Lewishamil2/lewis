一键拆表工具 V4.1（tkinter 版，替代 WPS 智能工具箱会员功能）
海上钢琴师出品（不是上海钢琴师，不是上海~不是上海）

用法：选择 Excel 文件 -> 选工作表 -> 选拆分依据列 -> 可选数据起始行 -> 一键拆分
支持两种模式：
  1. 拆到当前工作簿：在原文件内按取值生成多个工作表（原表保留，自动备份）
  2. 拆成多个文件：每个取值生成一个独立 xlsx 到指定文件夹


====================  V4.1 修好了什么（相对 V4）  ====================

【重要 · 拆大表格报「IndexError: list index out of range」】
  这是本次最核心的修复。有用户反馈拆大表格时弹窗报错 IndexError。
  原因：xlsx 里每个单元格的样式，存的是一串"编号"（第几号字体、第几号填充、
  第几号对齐…），这些编号对应的是**源文件**里的样式清单。
  V4 直接把编号抄进了新文件，但「拆成多个文件」时每个新文件都是全新的空工作簿，
  它的样式清单里只有默认的那一两条。编号一查就越界了 —— 于是保存时报 IndexError。
  表格越大、用到的样式越多（单元格对齐、换行、百分比/日期格式、自定义格式等），
  越容易踩到。V4.1 改成按"样式内容"逐个搬进新文件，并让程序自己登记编号，
  彻底解决；同时按样式去重，几百万单元格也不会变慢。

【报错信息不再看不出原因】
  V4 的报错弹窗只截取了最外面几层调用，真正的出错位置被切掉了，用户截图完全没法定位。
  V4.1 的弹窗会显示「外层调用位置 + 内层出错点」的首尾摘要，并且把**完整**的错误
  信息写到源文件旁边的「一键拆表-错误日志.txt」，方便直接发回来定位问题。

【样式保真】
  修复后不仅不报错，单元格样式（字体、字号、颜色、加粗、填充色、边框、对齐方式、
  自动换行、数字格式）与源表逐格一致，已验证 8 万多个单元格零差异。


====================  V4 修好了什么（相对 V3）  ====================

【重要 · 列变少 / 行变少】
  这是上一轮最核心的修复。xlsx 文件里有一个 <dimension> 标签，用来"声明"表格有多大。
  很多系统导出的文件里，这个声明和实际数据对不上（比如声明 200 列，实际只有 150 列）。
  V3 直接信了这个声明，于是：
    - 界面下拉框显示 200 列，拆出来的文件只有 150 列  -> "列变少"
    - 声明行数比实际少时，多出来的行被静默丢掉     -> "行变少"
  V4 起不再信任这个声明，改为直接扫描表格 XML 统计真实存在的行列，界面、预览、
  实际拷贝三处口径完全一致。同时，如果发现文件声明和实际不符，界面会明确提示你。

【数据安全】
  - 「拆到当前工作簿」保存前，会自动把原文件备份一份：原名.backup.xlsx

【速度】
  - 「拆成多个文件」时，源工作簿只加载一次（V3 是每个分组都重新加载一遍）
  - 拷贝时只遍历真正需要的行，不再每拆一个分组就把整张表扫一遍
  - 选列后的取值统计放到后台线程，大表统计期间界面不再假死

【输出文件】
  - 不再把原工作簿里的其它工作表带进每一个输出文件（V3 会带）
  - 文件名自动去重，不会互相覆盖
  - 补齐 Windows 非法字符（V3 漏了 < > " |），并限制长度，避免保存失败

【格式保留】
  - 合并单元格全部按行号保留（V3 只保留第 1 行的）
  - 条件格式的行号会跟着数据重排（V3 会指向错误的行）
  - 冻结窗格按数据起始行校正（V3 会错位）

【易用】
  - 列下拉框不再被 512 列上限截断（现在最多支持 16384 列）
  - 拆分结果会明确告诉你：有多少行因为拆分依据列是空的而被跳过
  - 预览区会显示源表的真实行列数
  - 源文件是 .xlsm（启用宏）时会提示宏不会保留


====================  相对 V2 的功能  ====================

  - 可指定数据起始行：第 1 行 ~ 起始行-1 视为表头，原样保留在每个拆分结果顶部；
    拆分扫描从起始行开始
  - 可选是否把空白行拆为「(空白)」表/文件


====================  使用建议  ====================

  - 大表（十几万单元格以上）第一次选列时，统计取值需要几十秒，属正常现象，
    界面不会卡住，状态栏会显示进度。
  - 「拆到当前工作簿」会重写源文件，虽然会自动备份，但建议对重要文件先手动另存一份。
  - 源文件是 .xlsm 且需要保留宏时，请用「拆成多个文件」。
  - 拆分依据列最好是没有空白的列；有空白的行默认不拆出，可勾选「空白行也拆出」。
  - 如果拆到一半失败，先去源文件所在文件夹看「一键拆表-错误日志.txt」，
    里面记录了完整的出错位置。


====================  自检  ====================

  如果怀疑程序有问题，可以运行自检：
      一键拆表-V4.1.exe --selftest 报告.txt
  程序会把环境与核心功能的检查结果写进 报告.txt（最后一行 RESULT=PASS 表示正常）。
